# User Management API

A secure RESTful API built with Node.js, Express, and TypeScript for managing user authentication, authorization, and data.

## Features

- OpenAPI 3.0.3 documentation


## Technical Evolution

### API Documentation

Implemented OpenAPI 3.0.3 specification:
- Comprehensive `openapi.yaml`
- Reusable component schemas
- Interactive Swagger UI at `/api-docs`
- Decoupled documentation from implementation
