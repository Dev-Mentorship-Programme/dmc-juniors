# Authentication & Authorization Resources for Junior Developers

Understanding authentication (verifying identity) and authorization (controlling access) is a critical skill for every backend and full-stack developer. Below are curated resources to help you build a strong foundation.

---

## 📘 Core Concepts

- [What is JSON Web Token (JWT)?](https://www.jwt.io/introduction#what-is-json-web-token-structure)  
  Learn the structure of JWTs and how they’re used for securely transmitting information between parties.

- [Role-Based Access Control (RBAC)](https://auth0.com/docs/manage-users/access-control/rbac)  
  Understand how roles and permissions help manage access to different parts of an application.

---

## 🔐 Authentication & Security Practices

- [Hashing Passwords: One-Way Road to Security](https://auth0.com/blog/hashing-passwords-one-way-road-to-security/)  
  Why passwords should **never** be stored in plain text and how hashing keeps user data safe.

- [OWASP Top Ten Security Risks](https://owasp.org/www-project-top-ten/)  
  Industry-standard list of the most critical web application security risks every developer should know.

---

## ⚙️ Implementation Resources

- [Using Middleware in Express.js](https://expressjs.com/en/guide/using-middleware.html)  
  Middleware is essential for handling authentication and authorization logic in Node.js applications.

---

## ✅ Suggested Learning Path

1. **Start with JWTs** → Understand tokens and why they’re important.  
2. **Learn about Password Hashing** → Build secure authentication systems.  
3. **Explore Middleware** → Implement authentication and authorization in Express apps.  
4. **Understand RBAC** → Manage users, roles, and permissions effectively.  
5. **Study OWASP Top Ten** → Be aware of the biggest threats and how to mitigate them.  

---

## 🎯 Goal

By going through these resources and exercises, you’ll be able to:

- Securely handle user authentication.  
- Manage authorization with roles and permissions.  
- Identify and mitigate common security risks.
