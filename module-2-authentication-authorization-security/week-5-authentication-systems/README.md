# Week 5: Authentication Systems

## Learning Objectives
- Understand authentication vs authorization concepts
- Implement JWT-based authentication
- Build OAuth 2.0 integration with social providers
- Create session-based authentication systems
- Implement multi-factor authentication
- Apply password hashing best practices

## Examples
1. **JWT Authentication** - Complete JWT implementation with refresh tokens
2. **OAuth 2.0 Integration** - Social login with Google and GitHub
3. **Session-Based Auth** - Traditional session management with Redis
4. **Multi-Factor Authentication** - TOTP implementation with authenticator apps

## Exercises
1. Implement custom JWT middleware
2. Add OAuth integration to existing API
3. Build secure password reset flow
4. Create API key management system

## Resources
- JWT.io for token debugging
- OAuth 2.0 specification
- OWASP authentication guidelines
- Password hashing best practices

## Setup Instructions
Each example folder contains its own README with specific setup instructions.
