# Exercise 1: JWT Authentication Implementation

## Objective
Build a complete JWT authentication system with custom middleware and token management.

## Requirements
1. Implement user registration with password validation
2. Create login system with account lockout protection
3. Build JWT token generation and validation
4. Implement refresh token rotation
5. Add password reset functionality

## Tasks
1. **User Model Enhancement**
   - Add email verification fields
   - Implement password history tracking
   - Add two-factor authentication support

2. **Authentication Middleware**
   - Create role-based authorization
   - Implement IP-based restrictions
   - Add device tracking

3. **Security Features**
   - Rate limiting for auth endpoints
   - Suspicious activity detection
   - Session management

## Deliverables
- Complete authentication API
- Postman collection for testing
- Security audit report

## Evaluation Criteria
- Code quality and organization
- Security best practices implementation
- Error handling and validation
- Documentation completeness
